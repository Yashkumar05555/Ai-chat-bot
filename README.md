# 🤖 Cranes Versity AI Chatbot

Cranes Versity AI Chatbot is an AI-powered chatbot designed to help students with academic queries, course-related information, and learning support.

## 🚀 Features

- 💬 AI-powered chat interface
- 🎓 Student-focused academic assistance
- 📚 Course and subject-related queries
- ⚡ Fast and responsive UI
- 📱 Responsive design for desktop and mobile
- 🔐 Environment variable support for API configuration
- 🧠 AI assistant functionality

## 🛠️ Tech Stack

- React.js
- TypeScript
- Vite
- CSS
- AI / Gemini API
- Node.js
